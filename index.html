APOPHIS // SYNTHETIC LAB ENVIRONMENT
Öffentlicher Forschungsdemonstrator

Apophis

Offline Research Harness für nachvollziehbare Identitätsentscheidungen im synthetischen Übungslabor.

Die Forschungsfrage

Wie lassen sich einfache Rollenentscheidungen in einem synthetischen Identitätsablauf so dokumentieren, dass Testeingabe, Sollentscheidung, beobachtetes Ergebnis und Integritätsdigest reproduzierbar zusammengehören, ohne operative oder personenbezogene Daten offenzulegen?

Der Demonstrator

Synthetische Rollen

Apophis nutzt fiktive Trainingsrollen und Demoobjekte statt realer Identitäten.

Evidence Bundles

Lokale Erzeugung von fälschungssicheren Belegen durch kanonische JSON-Digests.

Isolierte Umgebung

Keine Netzwerkverbindung, kein Zugriff auf externe Systeme – maximale Kontrolle.

Technischer Start

Unabhängige Forschende können den Harness lokal wie folgt erproben:

python -m harness.cli defence-demo
python -m harness.cli report /tmp/apophis-defence-demo-bundle.json
